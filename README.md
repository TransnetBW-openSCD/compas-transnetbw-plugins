## Publishing

Successful builds on `main` update the unversioned plugins. To publish a numbered
release, run **Actions > Release Plugin** on `main` after the desired build has
been deployed, choose the plugin and the version increment, and update this
release list afterwards.

The retired `bearingpoint/compas/plugins/` directory has been removed. Consumers
using those URLs must switch to an entry point listed above; no redirects are
provided.
